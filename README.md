# CeranWrap Studio

Free artistic nude wrap study **viewer (A)** + **interactive tools (B)** + **free drops / storefront (C)** + **free image generation prompt tool** with new features.

## Live

Open `index.html` or deploy as a static site (Vercel / GitHub Pages).

## Features

- **A – Gallery / viewer**: Study #001 linked to the Imagine wrap video
- **B – Interactive study**: Open video, still capture hooks, local tools
- **C – Free drops**: Still pack & prompt JSON export (\$0)
- **Free gen tool**: Pose, pressure slider, material/light/hands chips, multi-view, seed, history, presets, one-click copy
